# 7NRP Conference 2026

Materials from the 7NRP 2026 Conference, including presentations.

## Presentations

### 7NRP for ITS AI CoP (`7NRP-for-ITS-AI-CoP/`)

A slide presentation built with [Slidev](https://sli.dev/), a developer-friendly presentation framework powered by Vue and Markdown. The deck was vibe-coded using a mixture of [Claude Cowork](https://claude.ai) and [ChatGPT Codex](https://openai.com/codex).

#### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later recommended)

#### Running the presentation

```bash
# Navigate to the presentation directory
cd 7NRP-for-ITS-AI-CoP

# Install dependencies (first time only)
npm install

# Start the dev server and open the presentation in your browser
npm run dev
```

The presentation will be available at `http://localhost:3030` by default.

#### Other commands

```bash
# Build a static version of the presentation
npm run build

# Export slides to PDF
npm run export
```
